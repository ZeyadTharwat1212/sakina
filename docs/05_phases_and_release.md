# المراحل والتسليم والإطلاق

> القسمان 38 و39.

## المرحلة 1 — نسخة يومية أساسية (هذا التسليم)
**مُنجز**: هوية ونظام تصميم، استخدام كضيف، صفحة اليوم، قرآن كامل (Tanzil)، تفسيران، ترجمة إنجليزية، مواقيت وإعدادات وإشعارات، قبلة، أذكار، البخاري ومسلم (متن)، بحث، إعدادات، اختبارات، سجل مصادر.

**بوابات الإطلاق قبل المتجر (مستقلة بعضها عن بعض)**:
1. **الحقوق** — قرار الحديث: إذن sunnah.com أو استبدال المصدر. دون ذلك يُطلق التطبيق بالأربعين النووية فقط أو بدون قسم الحديث.
2. **المراجعة العلمية** — مراجع مسمّى يوقّع على: عيّنة التفسيرين، تخريج الأذكار (242 ذكرًا بلا مرجع)، نصوص الواجهة ذات الدلالة الفقهية (الضحى، منتصف الليل، الشروق).
3. **الأجهزة الحقيقية** — iPhone + Android متوسط: وصول الإشعارات في الخلفية والصامت وعدم الإزعاج وبعد إعادة التشغيل؛ قارئ الشاشة؛ قص التشكيل في Amiri عند أكبر حجم.
4. **المتجر** — سياسة خصوصية (التطبيق لا يجمع شيئًا، لكن المتجر يطلب نصًا)، لقطات، تصنيف العمر، إعلان استخدام الموقع «على الجهاز فقط».

## المرحلة 2 — محتوى وتعلّم
تفاسير إضافية مرخصة، ترجمات أخرى، خطط ختمة وحفظ (تكرار/إخفاء/جدولة مراجعة)، رمضان (سحور/إفطار/تراويح/متوقع-معلن)، تذكيرات الصيام، الزكاة (مدخلات يدوية للأسعار)، الحج والعمرة (دليل دون إنترنت)، التعلم والسيرة والفقه بمصادر مراجعة، الودجت (Swift/Kotlin)، تنزيل الصوت إذا تأمّن إذن (أو Islamic Network CDN للاستخدام غير التجاري).

## المرحلة 3 — تكاملات اختيارية
الأذان الكامل (AlarmKit iOS 26+ / AlarmManager)، المساجد (OpenStreetMap)، الساعات، وضع الأطفال والأسرة، مساعد استرجاع **محلي فقط** إن وُجد نموذج يعمل على الجهاز، وإلا يُلغى (القيد: لا اعتماد على خدمة خارجية).

## التمويل
- الوصول الأساسي (القرآن، المواقيت، الأذكار، الحديث) مجاني دائمًا.
- لا إعلانات تقاطع القراءة أو الأذان — ويُفضَّل لا إعلانات إطلاقًا.
- خيارات: تبرع شفاف داخل التطبيق (IAP تبرع)، أو اشتراك اختياري لمزايا مكلفة فعلًا (تنزيل صوت عالي الجودة إذا كان له كلفة ترخيص).
- **لا تقدير تكلفة هنا** عمدًا: يُحدَّد بعد تحديد الفريق وأسعار المراجعة والترخيص الحالية (القسم 39).
